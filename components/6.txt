Build the "Faqs 1" section from Efferd UI. An elegant FAQ block: a heading column, an accordion of questions with smooth expand and collapse transitions, hairline dividers between items, and a support call to action beneath the list.

Stack: React + TypeScript + Tailwind CSS + shadcn/ui.
Dependencies: `@radix-ui/react-accordion`, `lucide-react`.

STEP 1. Install the accordion primitive if missing:
npx shadcn@latest add accordion


RULES THAT MUST NOT CHANGE
1. Accordion is `type="single"` with `collapsible`, so one answer opens at a time and clicking an open item closes it.
2. The default shadcn chevron is suppressed with `[&>svg]:hidden`. The plus that morphs into a minus is the intended affordance. Both icons are stacked in one `relative` box and cross fade with rotation, never swapped conditionally in JSX.
3. Item separation is a single `border-b` per item plus one `border-t` on the accordion root. Do not add per item boxes, cards, or rounded corners.
4. The section is a 5 column grid at `md`, heading taking 2 and accordion taking 3. It stacks to one column below that.
5. Keep `hover:no-underline` on the trigger. shadcn underlines triggers by default and it reads as a broken link here.
6. The support line sits outside the accordion at `mt-8`, small and muted, so it reads as a footnote rather than a second CTA.

VERIFICATION
- Confirm `border`, `muted-foreground`, and `primary` CSS variables exist in `globals.css`.
- If the project is not Next.js, replace `next/link` with a plain anchor and drop the import.
- shadcn ships the open and close height animation on `AccordionContent` via `data-[state]` keyframes in `tailwind.config`. Confirm `accordion-up` and `accordion-down` keyframes are present, otherwise the transition snaps instead of sliding.
- Test keyboard access: Tab to a trigger, press Enter and Space, and confirm the icon state flips with the panel.
- Return complete runnable files with all imports. No placeholders, no TODOs.
