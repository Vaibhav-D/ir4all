LAYOUT RULES TO PRESERVE
1. Section vertical rhythm is `py-32`. Do not reduce it.
2. Header block is centered, stacked, `gap-4`, with an outline Badge above an `h1` capped at `max-w-2xl`.
3. TabsList is vertical on mobile and horizontal from the `sm` breakpoint. Active trigger is `bg-muted` with `text-primary`, inactive is `text-muted-foreground`.
4. The tab panel is a single shared `bg-muted/70` rounded container wrapping all TabsContent, not one container per tab. Padding is `p-6` rising to `lg:p-16`.
5. Panel content is a two column grid only from `lg`, stacking below that with a `gap-20` vertical gap that tightens to `lg:gap-10` side by side.
6. Text column order is Badge, h3, paragraph, Button. Button is `size="lg"`, `w-fit`, left aligned.
7. Image is `rounded-xl` with no fixed width, letting the grid cell size it.

VERIFICATION
- Confirm `tailwind.config` has the `container` plugin settings your project uses, since `container mx-auto` drives the horizontal alignment.
- Confirm `muted`, `muted-foreground`, `primary`, and `background` CSS variables exist in `globals.css`. Missing tokens are the single most common reason this block renders wrong.
- Render the demo and check three states: mobile stacked, `sm` horizontal tabs, `lg` two column panel.
